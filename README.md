# Shop Profit Calculator PK

A simple mobile-friendly web app for shopkeepers in Pakistan.

## Run it
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages (mobile-friendly steps)
1. Sign in to GitHub and create a new repository, for example `shop-profit-calculator-pk`.
2. Upload all project files (`index.html`, `style.css`, `app.js`, and `manifest.json`) to the repository root.
3. Open the repository's **Settings** → **Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then press **Save**.
6. Wait for GitHub Pages to publish the site. Open the URL shown in Settings → Pages.

## Important
- Sales records are stored in this browser on this device using localStorage.
- Records do not automatically sync between phones or browsers. Clearing browser data can remove them.
- This starter project does not include cloud backup, user accounts, ads, or payments.
- Test calculations and records before using it for real business accounts.
